# The AURA Gem — Powered by UBR AI

Single-page interactive site with three tabs: The Gem, The App (coming soon), and UBR AI.

## Structure
- `index.html` — all markup, styles and scripts (no build step)
- `assets/background.png` — hero background
- `assets/ubr-banner.png` — UBR banner above the footer

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```

## Deploy
Works as-is on GitHub Pages, Netlify or Vercel. Point the site root at this folder.

## Notes
- Fonts: Cinzel + Raleway (Google Fonts)
- The "Notify Me" email form is front-end only; connect it to a mail service (e.g. Formspree, Mailchimp) before launch.
- Brand colours: gold #c8902a / #e8b840, teal #00c8b8 / #00f0d8, navy #050d18.
